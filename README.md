# Jasper

Мультяшное лицо на Android, которое повторяет ваши выражения через фронтальную камеру.

## Внешний вид

- Чёрный фон
- Неоновые глаза (cyan) и улыбка (pink) — без лица
- Горизонтальная ориентация экрана

## Что умеет

- **Моргание** — закрывает глаза, когда вы моргаете
- **Поворот головы** — глаза и зрачки следуют за направлением взгляда
- **Улыбка** — рот расширяется и появляются румянецы
- **Живость** — лёгкое «дыхание», блики в глазах, плавные пружинные анимации

## Стек

- Kotlin + Jetpack Compose
- CameraX (фронтальная камера)
- ML Kit Face Detection (моргание, улыбка, углы поворота головы)

## Запуск

1. Откройте проект в **Android Studio** (Ladybug или новее)
2. Подключите телефон с Android 8+ или запустите эмулятор с камерой
3. Run → `app`

При первом запуске разрешите доступ к камере.

## Структура

```
app/src/main/kotlin/com/jasper/facemirror/
├── MainActivity.kt          — точка входа
├── model/FaceState.kt       — состояние лица (глаза, улыбка, поворот)
├── camera/FaceAnalyzer.kt   — ML Kit анализ кадров
└── ui/
    ├── FaceMirrorScreen.kt  — камера + разрешения
    └── NeonFace.kt           — неоновые глаза и улыбка
```
