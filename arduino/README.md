# Прошивка шасси Jasper

Скетч для Arduino-машинки с HC-06 и ультразвуковым датчиком. Android шлёт Bluetooth Classic SPP-команды вида `%A#`.

## Два режима

По умолчанию после включения — **старый код машинки** (LEGACY): импульсы, ультразвук сам объезжает на `%T#` / `%W#`, нет команды → стоп.

Когда Jasper открывает Bluetooth, телефон шлёт `%P#` и забирает шасси (**PHONE**): моторы держат последнюю команду, ультразвук **не** спорит с «вперёд». «Погуляй» / «за мной» по-прежнему идут как `%T#` / `%W#` — это явная просьба отдать руль датчику.

Выход из PHONE: `%O#` при закрытии приложения, или ~15 с без байт (телефон отвалился). Тогда снова LEGACY.

| Код | Действие |
|-----|----------|
| `%P#` | Режим телефона (keepalive, шлётся при коннекте и каждые 4 с) |
| `%O#` | Вернуть старую прошивку |
| `%A#` | Вперёд |
| `%B#` | Назад |
| `%C#` | Влево боком |
| `%D#` | Вправо боком |
| `%E#` | Поворот налево |
| `%F#` | Поворот направо |
| `%G#` … `%L#` | Диагонали и дрифт |
| `%T#` | Объезд препятствий (мозг машинки) |
| `%W#` | Следование за объектом (мозг машинки) |
| `%S#` | Стоп |

В PHONE команды A–L не импульсные: едет, пока телефон повторяет команду или не придёт `%S#`. Если повторы пропали на 0.8 с — стоп (телефон завис).

## Прошивка

1. Откройте `jasper_chassis/jasper_chassis.ino` в Arduino IDE.
2. Плата: Arduino Uno (или клон на ATmega328P).
3. Порт: USB машинки.
4. Sketch → Upload.

Bluetooth: SoftwareSerial на `A0` (RX) / `A1` (TX), 9600 бод.
Ультразвук: trig `A3`, echo `A2`.
