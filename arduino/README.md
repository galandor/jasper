# Прошивка шасси Jasper

Bluetooth HC-06: `A0` RX, `A1` TX, 9600. Ультразвук: `A3` trig, `A2` echo.

Телефон шлёт `%A#` … `%S#`. Arduino раз в ~120 мс отвечает строкой `D:<см>` (0 = нет эха).

Скорость моторов — константа `SPEED` в скетче. Пишите датасет на той же скорости, на которой потом хотите автопилот.

Прошить: Arduino IDE → плата Uno → порт USB машинки → Upload.
